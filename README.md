# TOP-etch-a-sketch
Click here! -> [Etch-A-Sketch](https://byjoelsamuel.github.io/TOP-etch-a-sketch/)

Presented above is a simple Etch-A-Sketch project created for TheOdinProject. 
- Hover your mouse over the grid to fill in colors and also mix colors when you hover them right beside each other! 
- Includes Functions, dot notations and constructors throughout the code to improve functionality while also being consise and easy to interact with!
